# SecurityLab Pro

SecurityLab Pro is an Android security toolkit
built with Kotlin and Jetpack Compose.

## Features in Version 1.0

- Security Dashboard
- Dark and Light Theme
- Authorized Assessment Setup UI
- Local JWT Header and Payload Decoder
- HTTPS URL Format Validator
- Security Headers Learning Guide
- Reports Screen
- GitHub Actions APK Build

## Important Limitations

This version does not perform remote vulnerability scanning.

JWT decoding does not verify token signatures.
HTTPS validation does not inspect server certificates.
Security header information is educational.

Only test systems you own or have explicit
written permission to assess.

## Build

Open the GitHub Actions tab and run:

Build SecurityLab Pro APK

Download the SecurityLab-Pro-debug artifact
after a successful build.
